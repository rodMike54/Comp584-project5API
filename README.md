
# COMP 584 - Project 5
## Chuck Norris Joke Generator

This project uses the Chuck Norris API to display
random jokes on a webpage.

 Features
- Fetch random jokes using JavaScript
- Choose different joke categories
- CSS card animation when displaying a joke
- Button to replay the animation
- Responsive layout using CSS Grid and Flexbox
- Error handling for failed API requests
